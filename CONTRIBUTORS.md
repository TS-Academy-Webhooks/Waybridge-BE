# Project Contributors

This repository houses a vital component of **Waybridge**, a dual-part **Logistics Webhook Management Platform** developed as the final Capstone Project for **TS Academy** by **Group 43**.

Waybridge relies on two distinct, complementary repositories working in tandem to deliver a unified, production-grade solution. Thank you to the dedicated engineering team who built, designed, and optimized this platform.

## Contribution Types

- 🎨 Frontend Engineering / UI / UX
- ⚙️ Backend Engineering / API / Architecture
- 📖 Documentation & Technical Writing
- 🐛 QA Testing & Debugging
